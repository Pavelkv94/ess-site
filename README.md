# English Stars School — сайт

Таплинк-стиль: колонка 480px, фиолетовый градиент #4B2EAA → #3A2389,
жёлтый #FFCE00, белые карточки, системный шрифт. Каждая страница
самодостаточная — стили, логотип и фото вшиты внутрь файла.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная-лендинг. Внизу — блок семейной скидки |
| `reading.html` | Курс «Читаю сам»: 4 ступени, 13 тем, цена, 3 отзыва |
| `prices.html` | Цены, 4 валюты + семейная скидка |
| `reviews.html` | 18 отзывов бесконечными слайдерами |
| `camp.html` | Летний лагерь, программа лета 2026 |
| `rules.html` | Памятка родителю: оплата, переносы + бонус за рекомендацию |
| `_redirects` | Старая ссылка /course ведёт на главную |

## Где что про скидки

- **Семейная скидка (–10%)** — на главной и на странице цен. Работает на новых.
- **Бонус за рекомендацию** — в памятке родителю. Для действующих семей.

## Как выложить

Netlify → ваш сайт → вкладка **Deploys** → перетащить папку целиком.

## Цены

В `prices.html` у каждой цены: `data-eur data-byn data-pln data-rub`.
PLN и RUB пересматривать раз в квартал. Цена курса — в тексте `reading.html`.
Семейная скидка показывается как «–10%» без вычисленных сумм — конкретную
цену называете в переписке, округляя по-человечески.
